# 苏州地铁 · 全站时刻

基于 **Vue 3 + TypeScript + Vite + Element Plus** 的中文站点时刻查询网站。线路、车站、方向、实时班次和周计划时刻来自用户提供的公开列车动态页面。

## 功能

- 按线路、车站、方向查询；跨线路搜索结果标明站名与所属线路。
- 最近两班车每10秒刷新，显示到本站的参考倒计时与预计到站时间。
- 周一至周日的完整计划时刻表独立切换；实时班次始终表示北京时间今天。
- 页面主题随线路颜色切换，浅色线路搭配深色文字。
- “首尾切换”只改变站点列表的显示顺序，不改变当前查询车站、方向或星期。
- URL保存查询选项，刷新及浏览器前进、后退可恢复；默认6号线金尚路往苏州新区火车站方向。
- 手机页面可展开选择车站；请求失败、数据过期、单方向暂无及空计划表分别展示。

原站实时数据精度为分钟，秒级倒计时仅据此推算。超过35秒未更新会停止倒计时和预计到站显示。实际以现场列车运行情况为准。


## 本地运行

推荐 Node.js 24 LTS，版本24.15或更新；也支持22.22.2及更新的22 LTS。

```text
npm ci
npm run dev
```

打开终端显示的本地地址，默认 `http://127.0.0.1:4175/`。Vite开发服务同时提供同源 `/api/*`，不需要额外启动后端端口。

```text
npm test
npm run type-check
npm run build
npm run preview
```

`npm test` 包含原生Node业务/路由测试和Vitest的Vue状态测试。`npm run preview` 在4176端口预览生产前端，并继续提供同源API。

## API与数据规则

- `/api/catalog`：线路及有序车站目录。
- `/api/live?line=6&station=金尚路`：当前站点各方向最近两班及采集时间。
- `/api/timetable?line=6&station=金尚路&direction=1&weekday=2`：所选星期、方向的计划时刻和方向选项。

站名按URL编码；`weekday` 为周一1至周日7。`direction` 使用接口返回的原站选项值，不由线路两端猜测方向。换乘站按“线路＋站名”定位，源页面的线路、站点、方向和星期均会校验。

唯亭的3／11号线贯通计划按原站已核实的规则处理：花桥方向归11号线，苏州新区火车站方向归3号线。仅该站、该线路组合与精确匹配的方向选项允许此规则，`sourceLine` 保留原始归属。

目录缓存24小时、实时缓存8秒、计划缓存5分钟。实时缓存区分线路、站点和北京时间日期；计划缓存区分线路、站点、方向和星期。目录过期后的下次请求重新解析原站，已打开页面刷新后可获取新目录；只有当前查看的站点会定时查询班次。

## 构建与部署

构建生成 `dist/client/`（Vue前端静态文件）和 `dist/server/index.js`（同源API及页面服务入口）。当前托管产物将前端资源内嵌在Worker中，不依赖额外的静态资源绑定。`.openai/hosting.json` 保留既有私有网站配置，原来的6号线通勤网站独立保留。

实时功能需要服务端请求和解析原站。单独发布 `dist/client/` 到GitHub Pages不能运行 `/api/*`；本次保持原站实时方案，不配置Pages或额外后端账户。

源站为 `http://106.14.198.252:8512/station`。服务端通过 `106-14-198-252.sslip.io:8512` 访问同一服务器，已核对公开A记录指向原IP，不经额外HTTP代理；此连接依赖sslip.io的DNS解析，用于满足托管平台的域名子请求要求。

服务端只发送原站公开的线路、站点、星期、方向界面偏好，不接收或存储用户登录凭据；上游地址固定，参数限定在有效目录及选项内。此项目为非官方独立展示，原始数据由原站维护。
