# 苏州地铁 · 全站时刻

独立的中文站点时刻查询网站，目录、方向、实时班次和计划时刻均来自用户提供的公开列车动态页面。原来的6号线通勤网站独立保留。

## 使用

选择线路、车站、方向，查看最近两班车和预计到本站时间。跨线路搜索结果同时标明站名与线路。计划时刻可单独切换周一至周日，按小时查看完整发车时间；实时班次始终表示北京时间今天。

默认选择6号线金尚路往苏州新区火车站方向，查询选择写入页面URL，刷新或复制地址可恢复。手机页面可展开选择车站。

原站实时数据精度为分钟，秒级倒计时只是据此推算。超过35秒未更新会停止倒计时和预计到站显示。实际请以现场列车运行情况为准。原站单方向的“暂无”不代表整站停运；查询失败也不代表没有计划班次。

## 本地运行和验证

需要 Node.js 22.13 或更新版本。

```text
npm install
npm run dev
node --test
node node_modules/typescript/bin/tsc --noEmit
npm run build
```

打开开发服务显示的本地地址。公开只读接口如下，参数中的站名按URL编码：

- `/api/catalog`：线路及有序车站目录。
- `/api/live?line=6&station=金尚路`：站点各方向最近两班及采集时间。
- `/api/timetable?line=6&station=金尚路&direction=1&weekday=2`：方向选项和所选星期、方向的完整计划时刻。

`weekday` 为周一1至周日7。`direction` 使用接口返回的原站选项值；方向名称不根据线路两端猜测。换乘站按“线路＋站名”定位，源页面返回的线路、站点、方向和星期均会校验。

唯亭站的3／11号线贯通计划有已核实的原站归属规则：花桥方向按11号线提供，苏州新区火车站方向按3号线提供。仅在唯亭、这两条线路和明确匹配的方向选项下接受此规则，接口通过 `sourceLine` 保留原始归属，其余错站、错线和错星期均拒绝。

目录缓存24小时、实时缓存8秒、计划缓存5分钟。实时缓存区分线路、站点和北京时间日期；计划缓存区分线路、站点、方向和星期。只有当前查看的站点会定时刷新。

## 数据连接和部署

源站为 `http://106.14.198.252:8512/station`。托管服务通过 `106-14-198-252.sslip.io:8512` 访问相同服务器；已验证该公共A记录指向原IP，不经额外HTTP代理。此方式满足Cloudflare Workers的域名子请求要求，依赖sslip.io提供DNS解析。开发模式使用原IP，以兼容本机代理DNS。

服务端只发送原站公开的线路、站点、星期、方向界面偏好，不接收或存储用户登录凭据。上游地址固定，查询参数仅接受目录中的站点和有效选项。

应用采用 React / Vinext，`.openai/hosting.json` 是该独立私有网站的部署配置。此项目为非官方独立展示，原始数据由原站维护。
